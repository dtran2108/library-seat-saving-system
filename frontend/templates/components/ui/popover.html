{# Popover — a ShadcnUI-style floating panel anchored to a trigger element. Vanilla-JS port of the Radix/Shadcn popover. Usage (define the popover body via `caller()`): {% from "components/ui/popover.html" import Popover %} {% call Popover(id="my-popover") %}

Anything goes here.
